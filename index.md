# Privacy Policy for PYDRA

**Last Updated: October 24, 2026**

## 1. Introduction

Welcome to PYDRA, an Android-based Python code editor and execution application.

This Privacy Policy explains how PYDRA handles user information, Python code, local files, internet access, and data sharing.

By using PYDRA, you acknowledge the data practices described in this policy.

## 2. Information We Collect

PYDRA does not require users to register, create an account, or provide personal information to use its core features.

The current version does not include built-in advertising, Firebase Analytics, cloud synchronization, or online AI features.

Based on the application functionality reviewed, PYDRA is designed to store user-created Python projects locally rather than upload them to a developer-operated server.

However, user-written Python programs and third-party services may process or transmit information as described below.

## 3. Local Storage of Python Files

PYDRA stores Python project files in the application's private internal storage by default.

These files may include:

- Python source code written by users.
- Project files created or edited within the application.
- Locally generated files and outputs.

Users can edit, rename, save, and delete supported project files.

PYDRA also allows users to export Python files to a location of their choice using Android's system file picker.

## 4. Internet Access

PYDRA requests Android's INTERNET permission to support internet-enabled Python functionality.

Python programs executed by users may communicate with external websites, APIs, and online services.

When users execute code that sends information to an external service, that service may receive and process the transmitted information according to its own privacy practices.

Users are responsible for reviewing and understanding the Python programs they execute.

## 5. Sharing and Exporting Code

PYDRA provides features that allow users to share Python code with other applications and export files to device storage.

Sharing is initiated by the user.

When users share code through third-party applications, such as messaging or email services, those applications may process the shared information according to their respective privacy policies.

When users select a cloud-based document provider for file export, the exported files may be stored by that provider.

## 6. Advertising and Analytics

The current version of PYDRA does not include an integrated advertising SDK or Firebase Analytics.

Advertising or analytics functionality may be introduced in future versions.

If such features are introduced, this Privacy Policy will be updated to describe the applicable information collection, processing, and sharing practices.

## 7. Data Storage, Backup, and Retention

PYDRA stores project files locally within its app-private storage.

Android's backup and restore functionality may include eligible application files, depending on device settings, Android backup rules, and available backup services.

PYDRA does not currently provide a separate developer-operated cloud synchronization or online project backup service.

Local project files generally remain available until they are deleted, application data is cleared, or the application is uninstalled, subject to Android's backup and restore behavior.

## 8. Data Deletion

Users can delete individual Python project files within PYDRA, subject to the application's requirement to retain at least one project file.

Users may also clear PYDRA's application data or uninstall the application through Android settings to remove its locally stored app data.

Previously created Android backups and files exported or shared with other applications may remain separately and are not automatically deleted by PYDRA.

## 9. Data Security

PYDRA uses Android's application-private storage for its default project files.

However, no software environment or storage system can guarantee absolute security.

Users should avoid executing untrusted Python programs or sharing sensitive information through unknown services.

## 10. Third-Party Services and Libraries

PYDRA includes Python libraries that support programming functionality, including Requests, Pillow, NumPy, and Matplotlib.

Some libraries, particularly Requests, can enable user-written Python programs to communicate with external services.

The privacy practices of those external services are governed by their respective policies.

## 11. Children's Privacy

PYDRA is a general-purpose programming and educational tool.

The current version does not require users to create accounts or provide personal information to access its core programming features.

Any additional requirements applicable to children or particular age groups will be addressed in accordance with relevant laws and distribution-platform policies.

## 12. Changes to This Privacy Policy

We may update this Privacy Policy to reflect changes in PYDRA's functionality, data handling, third-party integrations, or legal requirements.

Updates will be reflected by revising the "Last Updated" date.
